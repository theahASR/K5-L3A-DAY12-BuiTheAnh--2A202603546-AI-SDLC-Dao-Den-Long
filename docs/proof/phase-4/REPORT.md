## 2. Benchmark Optimization Evidence (Intel UHD Graphics 620)
- **Baseline (`MeshStandardMaterial` + `PCFSoftShadowMap 1024` + 72 uninstanced transparent cloud puffs):** `avg_fps = 30.5`, `frames = 917`, `p95 = 53.4 ms`.
- **Optimized (`MeshLambertMaterial` + `BasicShadowMap 512` + GPU-instanced clouds/shades/motes + zero-alloc flat 4×4 matrix writes, applied identically to gameplay & bench):** **`avg_fps = 44.9` (+47.2%)**, `frames = 1347`, `p95 = 43.9 ms`, `load_ms = 8943 ms`.

## 3. Independent Audit Sign-Off
The read-only `Phase 4 Release Auditor` confirmed 0 regressions in `src/core/simulation.ts` and caught 8 concrete issues (static server path-prefix check, leaderboard XSS via `innerHTML`, NFD Vietnamese normalization, fallback keybind guards, Night Intro campaign reset, live shade arrow tracking, `--seed 0` parsing, early browser close rejection). All 8 were fixed before running final verification and tagging `phase-4`.
