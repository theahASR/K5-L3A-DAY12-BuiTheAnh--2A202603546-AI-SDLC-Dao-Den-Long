## 2. Phase 2 Evaluation
- **What passed:** 23/23 Vitest tests (18 unit + 5 CLI), all 3 Phase 1 regression scenarios, all 7 Phase 2 feature scenarios, and a full 21,600-tick Night 3 run finishing in **0.95 seconds** (31× faster than the 30s limit) with byte-identical SHA-256 determinism.
- **Phase 1 Regression:** Zero unintended regressions. All Phase 1 test adjustments (carry 5→10, lantern cost 5→10, pulse cost 1→3, score moved from pickup to deposit) are explicitly documented in `docs/notes/phase-2-spec.md` and commented in `tests/simulation.test.ts`.
- **Independent Audit Impact:** Running an independent `research` subagent (`Phase 2 Contract Auditor`) caught 8 real issues before tagging — including air-dash tick-12 altitude drop, Night 3 Tier 2 Drifter elevation vs 3D Pulse immunity, rim-lantern safe-zone ejection into void, 59-tick recoil, 599-tick charm, and `idle` Drifter stealing. All 8 were fixed and locked down with regression tests.
